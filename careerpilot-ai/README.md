# CareerPilot AI 🚀

**An AI-powered job application assistant built with Google Gemini.**

CareerPilot AI helps job seekers prepare for job applications by analyzing resumes against job descriptions and generating tailored application materials.

## ✨ Features

- **Resume Analysis:** Get AI-generated feedback on your resume.
- **Job Match Analysis:** Identify relevant skills and potential skill gaps based on a job description.
- **Cover Letter Generator:** Generate a job-specific cover letter.
- **Interview Preparation:** Generate relevant interview questions to help prepare for a role.
- **Responsive Interface:** Use the application on desktop and mobile devices.

## 🛠️ Technology Stack

- Frontend: TypeScript, Vite, HTML and CSS
- Backend: Node.js and Express
- AI Integration: Google Gemini API
- Testing: Project test suite

## 🔐 API Configuration

The application uses the `GEMINI_API_KEY` environment variable for Gemini API requests. Configure the API key securely in your deployment environment. **Never commit actual API keys or `.env` files to GitHub.**

See `.env.example` for the expected environment variables.

## 🚀 Getting Started

1. Clone this repository.
2. Install the project dependencies using the package manager and lockfile provided by the project.
3. Configure the required environment variables.
4. Start the application using the scripts defined in `package.json`.

Check the project configuration for the exact commands and runtime requirements.

## 🎯 Project Objective

CareerPilot AI demonstrates how generative AI can support resume analysis, job matching, cover-letter drafting, and interview preparation in a single application.
